## 1 what the app is
- A notes app: each note has a title and a body, kept in a list you can open, edit and delete

## 2 the stack
- HTML, CSS, JavaScript, localStorage, GitHub Pages, with no framework, no build step and no backend

## 3 how to run it:
- open index.html in a browser

## 4 plain rules
- do not add any new libraries without asking first
- keep everything in index.html, style.css and app.js

## General rules
- store notes under the key notes-app:notes only
- never store passwords, keys or tokens
